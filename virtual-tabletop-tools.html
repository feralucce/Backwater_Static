Virtual Tabletop Tools

Three extensions built for 20 Below

Three Owlbear Rodeo extensions built specifically for 20 Below's rules, for running this campaign at a real virtual table. None of them touch a character sheet directly - they work off character JSON files exported from the 20 Below character creator's Sheet step, so anyone can use them without giving up their own copy of the app.

20 Below Dice
Player-facing · roller

Rolls the actual game mechanic instead of a generic dice box: the core 2d10 roll-under Skill check (Attribute + Difficulty, with the Element tickbox, Skill Tier, and Advantage/Disadvantage all handled for you), weapon Damage resolved die-by-die against a target's Soak/Presence/Psyche, Initiative, and a contested Potence-style Pool. Every roll posts to a log visible to everyone in the room, like an announced roll at a real table.

Optionally load your own character in its Char tab (read-only - it doesn't edit anything) and the roller links to it: picking a Skill fills in its Tier, clicking an Element fills in that Attribute, and Damage/Init/Pool get one-click fills from your sub-stats.

Install URL - paste into Owlbear Rodeo's Add Extension dialog
https://feralucce.github.io/20_Below_Dice/manifest.json

20 Below Roster
GM-facing · lookup

A GM's own roster, not a player tool. Load every player's character JSON alongside any NPC exports, get them as a simple list, click a name to see their full sheet - Figured Characteristics, Attributes, Skills, Boons, Resources, Gifts, Flaws, Scars. No editing, no dice, nothing but the lookup you actually need mid-scene when someone asks "wait, what's my Defense again?" or you need an NPC's stats on short notice.

The roster persists between sessions (saved to your browser), so it only needs to be built once and then just grows as new NPCs get exported.

20 Below Bestiary
GM-facing · scene tokens

Roster's counterpart for monsters and NPCs, but this one touches the scene. Load whichever monster JSONs you've prepped for tonight, get them as a list, and drop a real token onto the map with one click - centered on your current view with a small random offset so repeated clicks don't stack. Anything without finished token art yet gets a generated placeholder (colored ring, initials) instead, so a missing image never blocks play.

Click a name to see its full sheet, same layout as Roster. The loaded list persists between sessions (saved to your browser).

Installing an Extension
How-to
  1. Open your room in Owlbear Rodeo and click the puzzle-piece icon in the left toolbar to open the Extensions panel.
  2. Click Add Extension (or the "+" at the top of that panel).
  3. Paste in the install URL for the tool you want (above) and confirm.
  4. The extension's icon appears in your room's action bar - click it any time to open the tool.

Extensions are installed per Owlbear Rodeo account, not per room - once added, they're available in every room you open. If a tool ever looks broken or stuck after an update (blank panel, missing icon), removing it and re-adding it with the same URL usually fixes it - Owlbear can hold onto a stale copy of the install info otherwise.
